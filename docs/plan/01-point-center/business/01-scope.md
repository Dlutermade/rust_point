# 01 — 邊界與非目標

> 商業視角:紅利點數中心管什麼、不管什麼、刻意不做什麼。

## 管

- 紅利點數的**發(結帳批次 + 行銷批次)、用(即時與兩階段)、過期、退、送、併帳**。
- 帳務**正確性**:不透支、可對帳、每筆有事由、重複請求只算一次。
- **查詢**:顧客自助(餘額、清單、快過期、過期紀錄、流水)與後台核對(明細、盤點、對帳、商家 Dashboard)。
- **多商家隔離**與大規模發放的可行性。

## 不管(交給別的系統)

| 不做 | 歸誰 |
|------|------|
| 活動辦不辦、發給誰、發多少的決策 | 行銷 |
| 顧客是誰、登入、身分驗證 | 會員 / 身分系統 |
| 收款、退款的金流 | 訂單 / 金流系統 |
| 點數折抵後的履約(出貨等) | 訂單 / 商品系統 |
| 通知顧客的實際推播 | 通知系統(向本系統訂閱事件) |

> **解耦原則**:紅利點數中心與**訂單中心**、會員系統等都是**各自獨立的系統**,只在邊界上以明確介面 / 事件往來,**不共享資料、不互相伸手**。例:結帳賺點——訂單中心管訂單與退貨(含等待期該不該入帳),點數中心只依指示批次入帳、管點數帳。

## 現階段不做

- **購物金 / 儲值金**:錢等值的儲值餘額(有換算率、接近顧客的錢、會計上近似真負債);本系統只做**紅利點數**。
- **等級 / 倍率**:會員等級的發點倍數等進階玩法。
- **點數折現**:只折抵,不換現金。
- **跨商家通用點**:點不在商家之間流通。
- **任意調整餘額**:沒有憑空加減的後門;所有增減都走既定能力。
- **凍結 / 停權**:帳號層級的風控(詐欺等)。
- **資料匯出**:對帳資料的檔案匯出。
