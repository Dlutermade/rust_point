# 03 — 商業詞彙表

> 商業視角:用商家與顧客聽得懂的話定義名詞,作為全文件的共同語言。刻意不含技術詞。

| 名詞 | 定義 |
|------|------|
| **紅利點數(點數)** | 顧客在某商家的可用回饋額度;消費賺取或活動發放,消費時**面值直接折抵**。用掉時對商家形成**費用**。loyalty points,非儲值。 |
| **購物金 / 儲值金** | 錢等值的儲值餘額(有換算率、接近顧客的錢);**不在本系統**,僅作對照。 |
| **商家** | 使用本系統的租戶;各商家的點數與帳務完全隔離。 |
| **顧客** | 持有並使用點數的人;身分由外部認定,本系統只認其識別。 |
| **餘額** | 顧客當下可用的點數總額(只計已生效、未過期)。 |
| **有效期** | 一筆點從「開始能用」到「到期」的期間;到期後不可用。 |
| **永久點** | 沒有到期的點(opt-in),生效後恆可用。 |
| **發點** | 給顧客點;兩種批次形態(見下)。 |
| **齊發批次(行銷)** | 行銷一次對一大批人發,**人人同金額、同設定**。 |
| **聚合批次(結帳)** | 各顧客結帳賺得的點聚合成一批,**每筆金額 / 設定不同**,經等待期入帳。 |
| **等待期** | 結帳賺得到實際入帳之間的等待(訂單結清 / 退貨期);期間尚未入帳、不可用。 |
| **用點 / 折抵** | 顧客拿點抵消費;**面值直接折抵,無換算比例**。 |
| **預留 / 確認 / 取消** | 兩階段用點:預留(暫扣佔位)→ 確認(定案)/ 取消(還回)。 |
| **處理中** | 顧客流水中對「預留中或已取消的預留」的統一顯示,不揭露內部週期。 |
| **過期** | 點數到期而失效。 |
| **退點** | 退還一筆**已確認兌換**用掉的點;必對應該兌換,累計不超過用掉的。 |
| **補償** | 商家額外加碼給點;走**發點**,不是退點。 |
| **送點 / 贈點** | 顧客把**可轉讓**的點送給另一顧客;收到的**不可再轉**。 |
| **可轉讓** | 一筆點能否被贈送;發點當下決定,之後不改。 |
| **併帳** | 顧客換帳號時把舊帳號的點全部搬到新帳號;**逐批保留**可轉讓性。 |
| **事由 / 來源** | 每筆增減對應的原因與單據(活動、訂單、退貨單、工單)。 |
| **費用 / 潛在費用 / 已實現費用** | 發點 = 承諾;用掉且未退未取消 = 已實現費用;未到期流通 = 潛在費用(見 [00 願景](00-vision.md))。 |
| **對帳單 / 費用單(未來)** | 由對帳服務產出,列出顧客使用點數對商家形成的費用。 |
| **對帳** | 核對點數帳目是否正確、有無漂移。 |
