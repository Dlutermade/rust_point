# 03 — 商業詞彙表

> 商業視角:用聽得懂的話定義名詞,作為全文件共同語言。附英文對應,讓 PO 與工程師對得上同一個字。
> ⚠️ 待 PO 核對。

## 三個實體

系統裡**只有三種可編輯的東西**,各自獨立、各自一份清單:

| 名詞 | 英文 | 定義 |
|------|------|------|
| **首頁模板** | `HomePageTemplate` | 首頁的一份內容 + 生效條件。同一站可以有多份(常態版、周年慶版、會員版…),訪客某一刻只看到其中一份。 |
| **頁首模板** | `HeaderTemplate` | 頁首的一份內容。同一站可以有多份,其中一份是**站台預設**。 |
| **頁尾模板** | `FooterTemplate` | 頁尾的一份內容。同上。 |

三者**沒有共同的上位分類**。首頁模板有網址、有 SEO、要跑完整生效條件;頁首 / 頁尾都沒有,只有「哪一份是站台預設」。

> 未來的商品頁、活動頁、自訂頁各自是**另一種實體**(`ProductPageTemplate`…),不是首頁模板的一個「類型欄位」。

## 訪客看到的那一頁

| 名詞 | 英文 | 定義 |
|------|------|------|
| **頁面** | `Page` | **訪客看到的那一頁**,= 解析出的首頁模板 + 頁首 + 頁尾。**不是實體**、資料庫裡沒有這張表,是渲染當下算出來的結果。 |
| **外框** | `Chrome` | 一個頁面套用的**「頁首 + 頁尾」這一對**。是解析的產物,**不是一種分類** —— 沒有「外框模板」這種東西,只有頁首模板和頁尾模板。 |
| **解析** | `resolve` | 訪客上門的當下,依「現在時間 + 訪客是誰 + 從哪來」算出該呈現哪一份模板。不是後台手動勾開關。 |

## 生效與定向

| 名詞 | 英文 | 定義 |
|------|------|------|
| **生效條件** | `Targeting` | 一份首頁模板帶的四個維度:**檔期**(時間)、**受眾**(是誰)、**來源**(從哪來)、**優先序**(重疊時誰勝)。沒設的維度 = 永遠命中。**只有首頁模板有**,頁首 / 頁尾不吃。 |
| **常態版** | `isFallback` | 首頁模板裡那份「沒人符合時就它」的底:不設任何條件、優先序最低。每站恆有一份 → 畫面永遠有東西。 |
| **站台預設** | `isSiteDefault` | 頁首 / 頁尾裡「全站標準用哪一份」。每種恆有一份。 |
| **頁面覆寫** | — | 某份首頁模板可以指定要套哪份頁首 / 頁尾;不指定 = 跟隨站台預設。兩者可分開指定。 |

## 內容怎麼組

| 名詞 | 英文 | 定義 |
|------|------|------|
| **區塊** | `Block` | **唯一的內容單元**。模板的內容 = 一棵區塊樹,由上而下、可巢狀(≤ 5 層)。 |
| **排版容器** | `container` / `stack` | 兩種區塊,讓子區塊**並排 / 分欄 / 上下堆疊 / 疊層**。排版靠它們做,沒有另一種「整寬區段」的單位。 |
| **區塊型別** | `BlockType` | 系統定義的一種區塊,宣告**可設定欄位(schema)+ preset**。v1 有 9 種(見 04)。 |
| **區塊庫** | — | 所有區塊型別的集合,商家從中拖入。 |
| **設定欄位** | `schema` | 一種型別能被商家改的欄位(文字 / 圖片 / url / 顏色 / 選單…)。 |
| **preset** | `preset` | 型別的預設配置,讓它能被「新增」拖入。 |
| **實例** | `BlockInstance` | 商家放到模板上的那一份區塊,帶自己的設定值。 |

## 桌機與手機

| 名詞 | 英文 | 定義 |
|------|------|------|
| **顯示裝置** | `DeviceVisibility` | 每個區塊可設**全部裝置 / 僅電腦 / 僅手機**。這是做出「電腦橫向選單、手機漢堡鈕」這種**結構差異**的方式。 |
| **分裝置設定值** | `PerDevice` | 部分設定(尺寸、間距、對齊…)**電腦與手機各存一份**,商家能讓兩邊排不一樣。哪些欄位可分裝置由該區塊型別的 schema 宣告。 |

## 其他

| 名詞 | 英文 | 定義 |
|------|------|------|
| **網址** | `slug` | 首頁模板的網址路徑。同一站不重複。 |
| **SEO** | `seo` | 首頁模板的標題 / 描述,供搜尋引擎索引。 |
| **全站設定** | `Theme` | 品牌色 / 字型 / logo 等全站共用設定。 |
| **草稿 / 發布** | `draft` / `active` | 編輯中(草稿,不上線)vs 對訪客上線(已發布)。**一經發布即凍結**,要改就複製一份新的。 |
| **暫停** | `paused` | 已發布的模板可暫停(不參與解析)、可恢復。常態版不可暫停。 |
| **異動紀錄** | `audit` | 建立 / 複製 / 調優先序 / 暫停 / 恢復 每筆留痕,可回溯「某個時間點線上是哪一份」。 |
| **互動 / 動作** | `Action` | 互動元素按下做的事;商家從動作目錄指定。 |
| **曝光** | — | 靠排區塊 + 生效條件決定曝光;沒有另一套投放系統。 |
| **多租戶** | `tenant` | 每商家各自的站。 |

## 已廢除的詞

| 曾用 | 現在 | 為什麼 |
|------|------|--------|
| **區段(Section)** | 區塊 | 沒有「整寬、可拖拉排序」這個獨立單位。排版由 `container` / `stack` 兩種區塊做,少一層概念。 |
| **區段組(Section Group)** | 頁首模板 / 頁尾模板 | 「設一次、套全站」已改成**站台預設 + 頁面可覆寫**,不是全站唯一的一組。 |
| **變體(Variant)** | 模板 | 實體就是模板;「同一版位的多個變體」= 同一種模板的多份。多一個字只是多一層翻譯。 |
| **版位(Slot)** | (三個實體各自的名字) | `slot` 在程式碼裡已被 Web Components 的 `<slot>` 佔用(排版容器投影子區塊用),領域再用一次會撞名。 |
| **頁面類型 / 頁面變體** | (各自是一種實體) | 首頁、商品頁、活動頁是**不同實體**,不是同一張表的類型欄位。 |
| **多裝置值** | 分裝置設定值 + 顯示裝置 | 拆成兩件事:數值各存一份(`PerDevice`)、結構顯不顯示(`DeviceVisibility`)。原本只講了前者,做不到漢堡選單。 |
