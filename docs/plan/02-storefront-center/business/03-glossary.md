# 03 — 商業詞彙表

> 商業視角:用聽得懂的話定義名詞,作為全文件共同語言。對標業界主流組頁模型的詞彙。
> ⚠️ 早期草擬,待 PO 核對。

| 名詞 | 定義 |
|------|------|
| **頁面(Page)** | 一個網址對應的前台頁;= 一串區段。電商 MPA,各頁獨立。 |
| **頁面類型 / 變體** | 頁面的類別(首頁、活動頁、自訂頁、商品頁…);同類型可有不同排法的變體。 |
| **區段(Section)** | 頁面的**整寬、可拖拉排序**單位。 |
| **區塊(Block)** | 區段內的內容單元;**可巢狀(≤ 5 層)**。 |
| **排版容器** | 一種區塊,用來讓子區塊**並排 / 分欄**(啟用巢狀)。 |
| **區段組(Section Group)** | header / footer / 公告等**共用區段**,設一次、套全站。 |
| **區塊型別** | 系統定義的一種區塊,宣告**可設定欄位(schema)+ preset**。 |
| **區塊庫** | 所有區塊型別的集合,商家從中拖入。 |
| **設定欄位(schema)** | 一種型別能被商家改的欄位(文字 / 圖片 / url / 顏色 / 選單…)。 |
| **preset** | 型別的預設配置,讓它能被「新增」拖入。 |
| **實例** | 商家放到頁面上的一份區段 / 區塊,帶設定值。 |
| **多裝置值** | 設定可分**桌機 / 手機**分別存,兩者可排不一樣。 |
| **全站設定(Theme)** | 品牌色 / 字型 / logo 等全站共用設定。 |
| **草稿 / 發布** | 編輯中(草稿)vs 對訪客上線(發布)。 |
| **SEO** | 頁面的標題 / 描述 / 網址,供搜尋引擎索引。 |
| **互動 / 動作** | 互動元素按下做的事;商家從動作目錄指定。 |
| **曝光** | 靠排區段 / 區塊決定曝光;沒有另一套投放系統。 |
| **多租戶** | 每商家各自的站。 |
