# 04 — 頁面模型

> 商業視角:訪客看到的一頁怎麼組成、後台實際編的是什麼。以 ASCII 示意,零技術。
> ⚠️ 待 PO 核對。詞彙見 [03](03-glossary.md);生效與定向的完整規則見 [09](09-variant-scheduling-and-targeting.md)。

## 後台編的是三種東西

系統裡只有**三種可編輯的實體**,各自一份清單、各自獨立:

```
首頁模板  HomePageTemplate   多份 ── 常態版 / 周年慶版 / 會員版 …
頁首模板  HeaderTemplate     多份 ── 其中一份是站台預設
頁尾模板  FooterTemplate     多份 ── 其中一份是站台預設
```

三者**沒有共同的上位分類**,能做的事也不同:

| | 首頁模板 | 頁首 / 頁尾模板 |
|---|---|---|
| SEO 標題 / 描述 | ✅ | ❌ |
| 生效條件(檔期 / 受眾 / 來源 / 優先序) | ✅ 完整 | ❌ 不吃 |
| 「哪一份是預設」 | 常態版(永久兜底) | 站台預設 |
| 可指定要套哪個頁首 / 頁尾 | ✅ | ❌ |

> 未來的商品頁、活動頁、自訂頁**各自是另一種實體**,不是首頁模板上的一個「類型」欄位。

## 訪客看到的一頁 = 解析出來的結果

「頁面」**不是後台編的東西**,是訪客上門的當下**算出來的**:

```
訪客請求  example.com/
    │
    ├── 首頁模板群 ──► resolve(現在時間 / 訪客是誰 / 從哪來) ──► 周年慶版
    │                                                             │
    │                                        這份指定要套哪個頁首 / 頁尾?
    │                                        ├─ 有指定 ──► 用它指的那份
    │                                        └─ 沒指定 ──► 站台預設
    │
    ├── 頁首模板群 ──► 被指定的那份,否則站台預設
    └── 頁尾模板群 ──► 被指定的那份,否則站台預設
                            │
                            ▼
                  訪客看到的一頁(Page)
                = 頁首 + 首頁內容 + 頁尾
```

頁首 + 頁尾這一對合稱**外框(Chrome)** —— 它是**解析的產物**,不是一種可編輯的東西。後台沒有「外框」這個清單。

**恆有一份兜底**:首頁模板一定有一份常態版(不設條件、優先序最低),頁首 / 頁尾一定有一份站台預設 → 畫面永遠有東西,不會開天窗。

## 內容 = 一棵區塊樹

模板的內容是**區塊(Block)**組成的樹,由上而下、可巢狀(至多 5 層)。**沒有「區段」這一層** —— 排版由兩種區塊做:

- **容器(container)**:水平 / 垂直排列子區塊,可設對齊、換行、間距、內距、背景、圓角、邊框、陰影。並排與分欄靠它。
- **疊層(stack)**:子區塊**互相疊在一起**,各自用九宮格位置定位。大圖上疊文字與按鈕靠它。

```
首頁內容
└─ 容器(垂直)
   ├─ 疊層 ── Hero
   │  ├─ 圖片(置中鋪底)
   │  ├─ 標題(置中)
   │  └─ 按鈕(下方置中)
   ├─ 容器(垂直) ── 最新消息
   │  ├─ 標題
   │  ├─ 文字
   │  └─ 分隔線
   └─ 容器(水平) ── 促銷三欄
      ├─ 圖片
      ├─ 圖片
      └─ 圖片
```

## v1 的區塊型別(9 種)

| 類 | 型別 | |
|---|---|---|
| **內容** | 標題 `heading`、文字 `text`、圖片 `image`、圖示 `icon`、按鈕 `button` | 放內容 |
| **排版** | 容器 `container`、疊層 `stack` | 裝別的區塊 |
| **分隔** | 分隔線 `divider`、間距 `spacer` | 撐開 / 隔開 |

這 9 種是**組合原語**,不是成品樣板 —— Hero、最新消息、促銷區都是**拼出來的**,不是各自一種型別。

> 商品清單等資料型區塊,等商品中心接上前台才補。

**每種型別宣告**:

- **設定欄位(schema)**:商家能改哪些。控制項有文字 / 多行 / richtext、圖片、url、顏色、選單、開關、數值、間距、對齊。
- **preset**:預設樣子 → 才能從「新增」面板被拖入。
- **實例**:商家放上去的那一份,帶自己的設定值。

## 桌機與手機

電商的頁首 / 頁尾在兩個裝置上**結構就不一樣**(電腦是橫向選單,手機是漢堡鈕),所以不只是尺寸縮放。兩個機制:

**① 顯示裝置** —— 每個區塊選一個:**全部裝置 / 僅電腦 / 僅手機**。

```
頁首模板(一棵樹)
├─ 圖片  logo        [全部裝置]
├─ 容器  橫向選單     [僅電腦]    ← 手機不出現
│  ├─ 按鈕 首頁
│  ├─ 按鈕 活動
│  └─ 按鈕 關於
├─ 圖示  搜尋        [全部裝置]
└─ 圖示  漢堡        [僅手機]    ← 電腦不出現
```

**② 分裝置設定值** —— 部分設定**電腦與手機各存一份**:

```
容器.方向   電腦 水平      手機 垂直      ← 三欄變一欄靠這個
容器.間距   電腦 24        手機 8
容器.內距   電腦 32        手機 16
寬度        電腦 貼齊內容  手機 填滿
```

**哪些欄位可分裝置由該型別的 schema 宣告**,不是每個欄位都能分:

| 分裝置 | 不分裝置 |
|---|---|
| 排法 —— 方向、對齊、換行、間距、內距、尺寸、高度 | 內容 —— 文字、圖片、動作 |
| | 品牌樣式 —— 顏色、圓角、邊框、陰影 |
| | 語意 —— 標題層級(h1/h2 隨裝置變會弄壞 SEO 與螢幕閱讀器) |

要讓兩個裝置顯示**不同內容**(不同圖、不同文案),做法是**放兩個區塊各自設顯示裝置**,不是同一個區塊分裝置。

**一棵樹、一次發布、一份異動紀錄** —— 不是「電腦一棵樹、手機另一棵樹」。logo 換一次兩邊都換。

## 首頁模板帶的東西

- **SEO**:標題 / 描述。同一網址的不同模板可以各有一套(周年慶版換標題)。
- **生效條件**:檔期 / 受眾 / 來源 / 優先序(見 [09](09-variant-scheduling-and-targeting.md))。
- **外框覆寫**:要套哪份頁首 / 哪份頁尾;**兩者可分開指定**,沒指定的跟隨站台預設。
- **草稿 / 發布**狀態。發布即凍結,要改就複製一份。

## 全站設定(Theme)

品牌色、字型、logo 等**全站設定一次**,三種模板共用。

## 互動

互動元素(按鈕 / 圖示)由商家指定「按下去做什麼」(去某頁 / 開新分頁 / 去登入…),從系統動作目錄挑。

## 首頁 wireframe

```
┌───────────────────────────────────────────┐
│ [logo]  首頁 活動 關於              🔍    │ ← 頁首模板(站台預設或被指定)
╞═══════════════════════════════════════════╡
│ 疊層:大圖 + 標題 + 按鈕                   │ ┐
│    ███「立即逛」→ 動作 ███                │ │
├───────────────────────────────────────────┤ │
│ 容器(垂直):最新消息                      │ │ 首頁模板
│    標題 / 文字 / 分隔線                   │ │ (resolve 選出的那份)
├───────────────────────────────────────────┤ │
│ 容器(水平):促銷三欄                      │ │
│    [ 圖片 ]    [ 圖片 ]    [ 圖片 ]       │ ┘
╞═══════════════════════════════════════════╡
│ 關於 · 客服 · 條款 · ©                    │ ← 頁尾模板(站台預設或被指定)
└───────────────────────────────────────────┘
```

手機版是**同一棵樹**,靠顯示裝置與分裝置設定值變形 —— 橫向選單換成漢堡、三欄變一欄。
