# 04 — 頁面模型(對標業界主流組頁模型)

> 商業視角:前台頁面怎麼組成——採業界主流的成熟組頁模型。以 ASCII 示意,供你驗證。零技術。
> ⚠️ 草擬,待 PO 核對。

## 一頁 = 區段(Section)的清單

一個頁面 = 一串**區段(Section)**,由上而下排列。區段是**整寬、可拖拉排序**的單位。

```
首頁 (Page)
├─ Header ───────── 共用區段組(套全站)
├─ 區段:Hero
├─ 區段:最新消息
├─ 區段:促銷
└─ Footer ───────── 共用區段組(套全站)
```

## 區段內含區塊(Block),區塊可巢狀(≤ 5 層)

每個區段裡放**區塊(Block)**;區塊可**巢狀**(容器裡放區塊,至多 5 層)。這樣能並排、能做複雜排版。

```
區段:促銷
└─ 容器(一排三欄)
   ├─ [ banner ]
   ├─ [ 圖片 ]
   └─ [ 圖片 ]
```

巢狀更深的例子(兩欄,右欄裡再上下疊):

```
區段:主打
└─ 容器(兩欄)
   ├─ 左欄 └─ [ 圖片 ]
   └─ 右欄 └─ 容器(上下)├─ [ banner ]  └─ [ 文字 ]
```

## 共用區段組:Header / Footer /(公告)

Header、Footer(及公告列)不屬單頁,放進**區段組**——**設一次、套全站**。

```
每一頁 = [ Header 組 ] + [ 頁面主體(各頁自訂區段) ] + [ Footer 組 ]
```

## 首頁 wireframe(區段視角)

```
┌───────────────────────────────────────────┐
│ HEADER  [logo] 首頁 活動 關於        🔍   │ ← 共用區段組
╞═══════════════════════════════════════════╡
│ 區段:Hero                                 │
│    ███ 大圖 +「立即逛」按鈕 →動作 ███      │
├───────────────────────────────────────────┤
│ 區段:最新消息(文字清單)                  │
│    • …………   • …………   • …………             │
├───────────────────────────────────────────┤
│ 區段:促銷 ── 容器(三欄)                  │
│    [ banner ]     [ 圖片 ]     [ 圖片 ]    │
├───────────────────────────────────────────┤
│ FOOTER  關於 · 客服 · 條款 · ©            │ ← 共用區段組
└───────────────────────────────────────────┘
```

## 區塊型別 = 設定 schema + preset(這就是「區塊庫」)

每種**區塊型別**(banner、文字清單、圖片、排版容器…)宣告:

- **可設定欄位(schema)**:商家能改哪些。
- **preset**:預設樣子 → 才能從「新增」面板被拖入。
- **實例** = 商家放到頁面上的那一份,帶自己的設定值。

**可設定欄位型別**(一組固定控制項,對標業界主流的 editor controls):

```
文字 / 多行 / richtext        圖片 / 影片 / 外部影片
url(外連或選內部頁)          顏色 / 漸層 / 配色
選單(select)/ 開關 / range   對齊 / padding(可分桌機·手機)
資源選擇器(商品/文章…)← 有商品後才用
```

## 多裝置值

版位、邊距、大小等設定**可分別存桌機 / 手機**(不只預覽切換)——商家能讓兩者排不一樣。

## 頁面實例帶的東西

- **頁面類型 + 變體**(同類型可有不同排法,如「商品頁」與「商品頁.鞋款」)。
- **網址 slug**、**SEO(標題 / 描述)**、**草稿 / 發布**狀態。

## 全站設定(Theme 全域)

品牌色、字型、logo 等**全站設定一次**,各頁共用。

## 互動

互動元素(按鈕)由商家指定「按下去做什麼」(去某頁 / 開新分頁 / 去登入…),從系統動作目錄挑。

## v1 先做的區塊型別

- **banner(含 Hero)、文字清單(如最新消息)、圖片、排版容器(欄 / 列,啟用並排與巢狀)**。
- 商品清單等資料型區塊,等商品中心接上前台才補。
