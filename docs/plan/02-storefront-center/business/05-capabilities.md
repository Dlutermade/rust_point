# 05 — 商業能力(編輯與發布)

> 商業視角:商家怎麼用前台中心——編輯、預覽、發布。對標業界主流組頁模型。以 ASCII 示意。零技術。
> ⚠️ 早期草擬,待 PO 核對。

## 編輯器:所見即所得

商家在後台編輯,像業界主流平台的主題編輯器,分三塊:

```
┌───────────┬────────────────────────────┬───────────────┐
│ 左:結構樹  │ 中:即時預覽(所見即所得)   │ 右:設定表單    │
│            │                            │               │
│ ▸ Header   │   [ 這裡就是前台長相 ]      │ (選中區塊的    │
│ ▾ 首頁      │   點區塊 → 右側出設定       │  可設定欄位,   │
│   ▸ Hero   │                            │  依 schema     │
│   ▸ 最新消息│                            │  自動生成)     │
│   ▾ 促銷    │                            │  圖片:[ 選 ]   │
│     ▸ 圖片  │                            │  文字:[____]   │
│     ▸ 圖片  │   [桌機] [手機] 切換        │  顏色:[ ■ ]    │
│ ▸ Footer   │                            │  ── 草稿│發布   │
└───────────┴────────────────────────────┴───────────────┘
```

- **左:結構樹**——區段 → 區塊(可巢狀);**拖拉排序、加、隱藏、複製、刪除**。
- **中:即時預覽**——所見即所得,點畫面上的區塊就選中它。
- **右:設定表單**——選中的區塊,依它**型別的 schema 自動長出**可改欄位。

## 從區塊庫加東西

點「新增」→ 從**區塊庫**挑型別(banner / 文字清單 / 圖片 / 排版容器…)→ 拖到位置。每型別帶 **preset**(預設樣子),拉進來就能用。

## 多裝置

切換**桌機 / 手機**;版位、邊距、大小等可**分別設值**——兩者能排不一樣。

## 共用區段組(一次套全站)

編輯 **header / footer /(公告)** 一次,全站每頁套用。

## 全站設定

改**品牌色、字型、logo**——全站生效。

## 頁面生命週期

```
建立頁面(選類型)→ 拖區塊 + 設定 → 預覽 → 草稿 ──發布──▶ 上線給訪客
                                            ▲                 │
                                            └──── 隨時回編輯、再發布 ◀┘
```

- **草稿**:編輯中,訪客看不到。
- **發布**:對訪客上線。
- 版本歷史 / 回溯、排程上架 → **延後**。

## 互動:給按鈕綁動作

選中按鈕 → 設定「**按下去做什麼**」(去某頁 / 開新分頁 / 去登入…),從系統**動作目錄**挑。
